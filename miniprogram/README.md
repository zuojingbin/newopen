# miniprogram（微信小程序：从聊天记录导入）

微信没有开放 API 允许第三方程序自动读取群聊消息/图片（这类"自动抓取"通常需要逆向微信内部协议，
违反《微信外部链接内容管理规范》，且账号会被限制/封禁），所以这里走的是官方开放、合规的路径：

用户在小程序里点一下「从聊天记录选择」，调起微信**原生**的聊天记录选择器
（`wx.chooseMessageFile`，官方文档：https://developers.weixin.qq.com/miniprogram/dev/api/media/file/wx.chooseMessageFile.html），
可以从**任意会话（包括群聊）**里勾选老师发的图片或文件，小程序拿到的是用户主动选中的临时文件，
再通过 `wx.uploadFile` 上传到后端 `server`，落到网页版正在使用的同一个「批次」里。

## 目录结构

原生（未用任何前端框架）微信小程序工程，用微信开发者工具直接打开 `miniprogram/` 目录即可：

- `app.json` / `app.js` / `app.wxss`：小程序入口配置
- `pages/index`：主页面——设置服务器地址入口、批次码、选择聊天记录文件/相册图片、上传
- `pages/settings`：填写/保存后端 `server` 的地址（存本地 storage，方便开发调试切换）

## 本地调试

1. 用微信开发者工具「导入项目」，目录选 `miniprogram/`，AppID 用测试号即可。
2. 开发工具里勾掉"不校验合法域名..."才能连到本地/自建的 `server`（仅调试期间，正式发布不能勾掉）。
3. 打开小程序后先进「设置」填后端地址（和网页版 `web/` 设置里填的是同一个地址）。
4. 「新建批次」或输入网页版给出的批次码「加入」，再「从聊天记录选择」勾选老师发的图片/PDF，点「上传」。
5. 回到网页版（`web/`）应该能在几秒内自动刷新看到新上传的文件。

## 正式发布前必须做的事

1. 后端 `server` 必须部署在**公网可访问的 HTTPS** 地址（微信小程序线上版本只允许请求 HTTPS 域名）。
2. 在[微信公众平台](https://mp.weixin.qq.com) → 开发 → 开发设置 → 服务器域名，把 `server` 的域名加到
   **request 合法域名**和**uploadFile 合法域名**列表里，否则线上小程序会请求失败。
3. 把 `project.config.json` 里的 `appid` 换成你自己申请的小程序 AppID。
4. 小程序涉及"上传文件"，提交审核时按实际用途填写即可（教辅资料打印工具），不涉及需要特殊资质的类目。

## 已知限制

- `wx.chooseMessageFile` 只能选到用户在微信里**主动点开过/收到过**的聊天记录文件，且受微信本地聊天记录
  保留策略影响（比如已清理的聊天记录选不到）——这是微信平台本身的限制，不是本项目能绕过的。
- HEIC（iPhone 相册常见格式）会被后端自动转成 JPEG 处理，无需在小程序端转换。
