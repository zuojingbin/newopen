# web（手机 + 电脑通用 PWA）

响应式网页应用，手机浏览器和电脑浏览器打开同一个地址即可使用，支持"添加到主屏幕"当作 App 用。

功能：
- 新建/加入一个"批次"，显示批次码给微信小程序端用来上传聊天记录里的图片/文件；
- 电脑拖拽 / 手机相册选择，直接把图片、PDF 导入同一批次；
- 拖拽缩略图调整顺序，或"自动排序"（按文件名数字/上传时间排序，兼容"第2页""10.jpg"这类命名）；
- 单张图片/PDF 页可手动标记为 A3，生成打印 PDF 时自动拆成两页 A4（自动识别 PDF 里真实的 A3 页面，图片按长宽比+像素启发式给出默认建议，可手动纠正）；
- 局域网扫描并添加 IPP 打印机、直接打印；跨网络的远程打印机通过 `printer-agent`（见 `../printer-agent`）注册后自动出现在列表里。

## 开发

```bash
npm install
npm run dev
```

首次打开会要求填写后端 `server` 的地址（"设置"页），本地开发时填 `http://localhost:4000`（或你启动 `server` 时用的端口）。

## 构建部署

```bash
npm run build
```

产物在 `dist/`，是纯静态文件，可以放到任意静态网站托管（Nginx、Vercel、对象存储等），
只要能通过 HTTPS 访问并把"设置"里的服务器地址指向你部署的 `server` 即可。手机需要能通过公网或同一 WiFi 访问该地址。
